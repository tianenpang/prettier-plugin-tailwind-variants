# Security

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.x     | Yes       |

## Report a vulnerability

Do not open a public issue.

Use [GitHub Security Advisories](https://github.com/tianenpang/prettier-plugin-tailwind-variants/security/advisories/new).

Include impact, repro steps (or a PoC), and affected versions or commit SHAs when you can.

You’ll hear back within a few days. Accepted reports get a fix and coordinated disclosure. Declined reports get a short reason.

## Scope

In scope: issues in released packages that can lead to unexpected code execution, prototype pollution, path traversal via options, or similar.

Out of scope: ordinary bugs, unrelated dependency CVEs, and problems in Prettier or `prettier-plugin-tailwindcss` (report those upstream).
