Before filing:

1. Confirm setup: compose with `prettier-plugin-tailwindcss` via `tailwindVariants(...)` — see the [README](./README.md).
2. Peers: Prettier v3+, `prettier-plugin-tailwindcss` v0.8+.
3. Search existing issues.
4. Include a small repro: config + input + expected vs actual.

Class order comes from `prettier-plugin-tailwindcss`. Questions about Tailwind CSS, the `tailwind-variants` runtime, or Prettier itself belong upstream.
